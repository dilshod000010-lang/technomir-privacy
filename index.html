Политика конфиденциальности Technomir

Дата обновления: 29 октября 2026 г.

Technomir уважает конфиденциальность своих клиентов и использует персональные данные только для обслуживания клиентов, обработки запросов, заказов и предоставления поддержки через WhatsApp.

Какие данные мы можем получать

Мы можем получать имя, номер телефона, содержание сообщений и другую информацию, которую пользователь добровольно отправляет нам через WhatsApp.

Как мы используем данные

Данные используются для ответа на обращения клиентов, предоставления информации о товарах, обработки заказов, доставки и клиентской поддержки.

Передача данных

Technomir не продаёт персональные данные клиентов третьим лицам. Данные могут обрабатываться только сервисами, необходимыми для работы WhatsApp и обслуживания клиентов.

Хранение и удаление данных

Мы храним данные только столько времени, сколько необходимо для обслуживания клиента и выполнения законных бизнес-задач. Пользователь может запросить удаление своих данных, обратившись в Technomir через официальный WhatsApp.

Контакты

По вопросам конфиденциальности и удаления данных свяжитесь с Technomir через наш официальный WhatsApp.
